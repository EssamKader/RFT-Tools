PART 1 -- the SAME +Hand bend, three different `normal`s

If all three build the same three curves, the normal does NOT
constrain the bend plane: the curves define it, and the normal is
free to stay the array axis R131 requires. That is the answer
#173 needs.

PART 2 -- does a BENT bar PIN like a straight one?

R22 is the tool's whole correctness argument for bar position:
never trust the coordinate handed to CreateFromCurves, pin every
handle to the host's own face afterwards. #92 measured a straight
4-bar set landing 12 mm off before that pinning went in.

The FIRST version of this probe asked for candidates with a method
name I invented, and every row came back '?'. This one calls what
the SHIPPED placer calls: GetConstraintCandidatesForHandle.
